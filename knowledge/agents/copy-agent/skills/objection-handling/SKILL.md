## 2. Metodología de Respuesta a Objeciones

Para que el manejo de objeciones convierta sin sonar a defensa corporativa, se usa la estructura **Validación + Giro + Evidencia**:
1. **Validación empática:** Reconocer la duda sin juzgarla (*"Es normal tener dudas si nunca fuiste"*).
2. **El Giro ("Ese es el punto"):** Reencuadrar la excusa como el motivo principal para hacerlo (*"No conocés a nadie: precisamente por eso vas a hacer amigos de verdad"*).
3. **Evidencia concreta:** Citar datos reales (ritmo adaptado, guía certificado, testimonios, políticas de cancelación claras).

## 3. Principio de Lenguaje
- Prohibido culpar al cliente o sonar condescendiente.
- El tono es de camaradería y tranquilidad: el guía ya llevó a cientos de personas con la misma duda exacta.
