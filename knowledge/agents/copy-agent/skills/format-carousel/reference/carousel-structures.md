# Estructuras de Carruseles Comprobadas

## 1. Carrusel Orgánico / Identificación (4 a 6 slides)
- **Slide 1:** Hook reflexivo o irónico (*"No siempre sabés qué querés, pero sabés cómo querés sentirte"*).
- **Slide 2:** Escena del sendero o grupo en movimiento.
- **Slide 3:** Contraste con el ruido o la rutina.
- **Slide 4:** Cierre emocional con destino y CTA suave para guardar o compartir.

## 2. Carrusel de Itinerario / Claridad Comercial (4 a 5 slides)
- **Slide 1:** Portada con destino y promesa (*"Todo lo que tenés que saber antes de subir al Chaltén"*).
- **Slide 2:** Día 1 o recorrido base (horarios, punto de encuentro, desnivel).
- **Slide 3:** Qué incluye (comidas, equipo, coordinación).
- **Slide 4:** Requisitos y qué llevar en la mochila.
- **Slide 5:** Fechas confirmadas, cupos restantes y CTA para reservar.

## 3. Carrusel de Ascenso / Desafío (5 a 7 slides)
- **Slide 1:** Portada con la cumbre y el desafío.
- **Slides 2-5:** La progresión del ascenso (la previa, el primer campamento, el ataque a cumbre, la vista final).
- **Slide final:** Convocatoria para la próxima fecha del ascenso.
