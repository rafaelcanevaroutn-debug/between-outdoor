# Vertical: Trail Running y Carreras de Montaña

## 1. El Mundo del Trail Runner
El trail running se mueve entre la disciplina física, la medición constante y el éxtasis de correr libre en la naturaleza. A diferencia del trekking contemplativo, aquí prima el ritmo, la intensidad, la superación personal y la comunión en carrera.

## 2. Vocabulario Técnico
- Singletrack, sendero técnico, desnivel positivo (`D+`), ritmo/pace, drop de zapatilla, bastones plegables, chaleco de hidratación, tiempo de corte, PR (Personal Record), pasaje por el filo, bajada técnica.
- **Tono:** Dinámico, enfocado en superación, datos métricos concretos (distancia, altimetría) y compañerismo en el esfuerzo.
