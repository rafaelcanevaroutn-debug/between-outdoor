# Patrones Validados — Trail Running

## 1. Lo que Convierte
- **Datos de Performance:** El corredor necesita números: distancia, desnivel acumulado y tiempo estimado.
- **El contraste Asfalto vs. Sendero:** El alivio mental de correr sin semáforos, sin humo y sin impacto constante de pavimento.
- **La llegada y la tribu:** Los abrazos, la hidratación compartida y la camaradería del grupo de entrenamiento.

## 2. Errores Críticos
- Tratar al corredor de trail como un caminante contemplativo.
- Omitir datos de altimetría o dificultad técnica del terreno.
