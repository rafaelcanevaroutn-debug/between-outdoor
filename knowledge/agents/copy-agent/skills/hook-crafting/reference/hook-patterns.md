# Banco de Patrones de Hooks

## 1. Formato Objeción ("... ese es el punto")
- *"Es que no conozco a nadie. Ese es el punto."*
- *"Es que no hay señal. Ese es el punto."*
- *"Es que me duelen las piernas. Ese es el punto."*
- *"Es que hace mucho frío ahora. Ese es el punto."*
- *"Es que no es para cualquiera. Ese es el punto."*

## 2. Formato Ironía / Humor sobre la Rutina
- *"La vida me pide mucho y yo solo quiero ir a un bosque."*
- *"No puedo tener planes → Los planes:"*
- *"Pop decidió no tener un sueldo fijo, pero se mudaron al sur."*
- *"Mi Instagram tiene que saber cómo era el lugar, no cómo llegué."*
- *"Un sándwich aplastado es todo lo que necesito."*

## 3. Formato Pregunta Incómoda o Reflexión
- *"¿De qué sirve estar vivo si no estás viviendo?"*
- *"Sin WiFi, sin señal, solo paz."*
- *"Soy más del árbol que de la gente."*
- *"Esto debería ser obligatorio una vez al mes."*

## 4. Formato Inmersión Directa (POV)
- *"POV: Llegás a la cumbre antes de que salga el sol."*
- *"El silencio que encontrás cuando dejás el teléfono en la mochila."*
