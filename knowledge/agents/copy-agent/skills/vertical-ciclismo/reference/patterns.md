# Patrones Validados — Ciclismo

## 1. Lo que Convierte
- Mostrar el tipo de suelo (tierra, piedra, asfalto roto).
- Explicar cómo viaja la bici (*"Transfer con portabicis homologados de punta a punta"*).
- El momento after-ride (el brindis o merienda al finalizar la etapa).

## 2. Errores Críticos
- Decir que un sendero técnico es "apto para todos" sin aclarar la destreza necesaria.
- No especificar distancia en km y desnivel.
