# TEMA: EQUIPO — TREKKING

## Propósito
Explicar qué llevar, elegir o revisar para una actividad concreta.

## Reglas
- Usar exclusivamente listas, requisitos o recomendaciones cargadas por el cliente.
- No prescribir botas, capas, impermeables, hidratación u otro elemento por conocimiento general.
- Explicar la función del elemento sin dramatizar consecuencias.
- No mezclar este tema con preparación física.
- Si no existe una lista verificada, cambiar de tema.
