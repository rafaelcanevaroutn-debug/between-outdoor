# TEMA: TESTIMONIOS — TREKKING

## Propósito
Mostrar una experiencia real mediante palabras, hechos o material aportado por participantes.

## Reglas
- Prohibido fabricar testimonios, citas, participantes, emociones o transformaciones.
- Identificar la fuente disponible antes de escribir.
- Se puede ordenar o resumir una declaración real sin cambiar su sentido.
- Si no existe testimonio verificable, no generar este tema; usar comunidad o ascenso factual.
- La experiencia particular no se presenta como resultado garantizado.
